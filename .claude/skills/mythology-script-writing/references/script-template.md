# Output template

Deliver in this exact shape (Markdown). Long-form: ~1200-2000 Hindi words.
Reel: 5 beats, ~150-220 words.

```markdown
# <Title> — <Prequel/Part N if series>

**Thread:** <character / boon / object>
**Echo pairs:** <Treta X ↔ Dwapar Y>, <…>, <…>
**Closing truth:** <one line>
**Duration target:** <mm:ss> (~<N> words) · **Sources:** <Valmiki Ramayana <kanda>, Mahabharata <parva>, Gita <ch.verse>…>

---

## ACT 1 — Series hook (00:00–00:20)

| # | VO (हिन्दी) | VISUAL | Subtitle (EN) |
|---|-------------|--------|---------------|
| 1 | … | Red stage curtain opens; title card | … |
| 2 | … | … | … |

## ACT 2 — Cold-open image (00:20–00:50)
…

## ACT 9 — Closing truth (12:20–13:00)
…

---

### Shloka sources
1. <Sanskrit> — <text, kanda/parva, sarga/adhyaya.verse> — <meaning>

### Notes for production
- Sets reused: <list>
- Folk/later-tradition elements used (labelled in VO): <list or "none">
```

Rules:
- One VO row ≈ one sentence ≈ 3-6 seconds.
- Mark pauses as `(…)` inside VO.
- Sanskrit rows: put Devanagari in VO and an English gloss in Subtitle.
- Subtitles: short, capitalised, ≤ 8 words per line (reference style: "THE WIND'S SON HEARD IT.").

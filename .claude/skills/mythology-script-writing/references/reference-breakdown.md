## Observations that matter for writing

1. **Thread**: Hanuman's boon ("jab tak Ram katha rahegi, main jeevit rahoonga")
   is both the plot engine and the theme — the film itself is Ram katha being told.
2. **Every Mahabharata beat has a Ramayana hook** — Maya = Ravan's
   father-in-law, Vibhishan pays tribute, Markandeya retells Ramayana,
   Yuyutsu = Vibhishan, Satyaki quotes Valmiki.
3. **Plant → payoff**: monkey on Arjuna's flag is promised at 07:30 and paid
   at 09:10 with a real Gita shloka.
4. **Emotional curve**: melancholy (empty ghat) → wonder (yug montage) →
   lightness (tail joke) → awe (giant form) → tension (war) → bitter wisdom (ending).
5. **Sanskrit is used ~5 times in 13 min**, always followed by meaning.
6. **Ending does not summarise**; it reframes. Last line is 4-6 words.
